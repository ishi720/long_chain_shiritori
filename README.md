# long_chain_shiritori

単語リストの中から、**一番長く続くしりとりの並び**を全探索で見つけるスクリプトです。

## 使い方

```bash
python main.py
```

実行すると、探索の進捗、最長のしりとりの長さと順番、探索時間が表示されます。

```
最長のしりとり: N

しりとりの順番:
  1. ○○○○ → X
  2. X○○○ → Y
  ...
```

## ルール

- 前の単語の**最後の文字**と、次の単語の**最初の文字**が同じならつながります。
- 同じ単語は 1 回しか使えません。
- 最後の文字の決め方
  - 最後が伸ばし棒「ー」のときは、その一つ前の文字を使います（例: コーヒー → `ヒ`）。
  - 最後が「♀」「♂」のときも同じく一つ前の文字を使います。
- 文字の正規化（最初の文字・最後の文字の両方に適用）
  - 小さい文字は大きい文字として扱います（`ァィゥェォャュョッヮ` → `アイウエオヤユヨツワ`）。  - 濁点・半濁点は区別します（`ド` と `ト` は別の文字）。
    濁点・半濁点を無視したい場合は、`normalize_char` 内のコメントアウトされた `dakuten_map` を有効にします。
- 「ン」で終わっても負けにはしません。ただし「ン」で始まる単語がなければ、そこで自然に止まります。
- どの単語から始めてもかまいません。

## アルゴリズム

しりとりを**グラフ上の最長経路問題**として扱い、深さ優先探索（DFS）とバックトラッキングで全通りを調べます。

### 1. グラフの構築（`build_graph`）

単語を「最初の文字」ごとにまとめた辞書を作ります。

```
{ 'リ': [(0, 'リンゴ'), (3, 'リス'), ...],
  'ゴ': [(1, 'ゴリラ'), ...], ... }
```

これで「`X` で終わる単語の次に来られる単語」をすぐに取り出せます。
同じ名前があっても区別できるように、単語はインデックスで管理します。

### 2. 深さ優先探索（`find_longest_path` / `dfs`）

1. すべての単語を 1 つずつ出発点にします。
2. 今の単語の最後の文字から、次につなげられる単語の候補をグラフで調べます。
3. まだ使っていない候補を 1 つ選んで `used` と `path` に追加し、再帰的に先へ進みます。
4. 戻ってきたら追加した単語を取り除き（バックトラック）、次の候補を試します。
5. 途中で `path` がそれまでの最長より長くなったら、`max_path` を更新します。

```
dfs(current, used, path):
    if len(path) > len(max_path): max_path = path のコピー
    for next in graph[last_char(current)]:
        if next が未使用:
            used に追加, path に追加
            dfs(next, used, path)
            path から削除, used から削除
```
